# 网申助手 · 招聘表单自动填充

Chrome / Edge 浏览器扩展（Manifest V3）。本地保存个人资料，在招聘网申页面一键扫描表单，
**逐字段预览确认后**自动填充姓名、学历、项目经历、成绩等信息。所有数据仅保存在本机，不上传任何服务器。

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角「开发人员模式」
3. 点击「加载已解压的扩展程序」，选择本项目根目录（包含 `manifest.json` 的目录）

## 使用流程

1. 点击浏览器工具栏扩展图标 →「管理我的资料」，填写并保存个人信息（支持多条教育经历 / 项目经历）
2. 打开目标招聘网站的网申页面
3. 点击扩展图标 →「扫描本页并填充」
4. 页面右侧弹出预览面板：
   - 已识别字段：核对「页面字段 → 填入值」的映射，可直接修改值、取消勾选不需要的项
   - 未识别控件：可手动指定对应字段（值自动带出，可修改）
5. 点击「确认填充」：成功字段绿色高亮，失败字段黄色高亮（请手动补填）

## 目录结构

```
├── manifest.json          # MV3 配置
├── lib/
│   ├── storage.js         # 资料本地存储（chrome.storage.local）
│   └── fields.js          # 字段定义与关键词表（识别规则核心）
├── options/               # 资料管理页（含 JSON 导入导出）
├── popup/                 # 工具栏弹窗（入口）
└── content/
    ├── detector.js        # 表单字段启发式识别引擎
    ├── filler.js          # 填充执行器（兼容 React/Vue 受控组件）
    ├── panel.js           # 逐字段预览确认面板（Shadow DOM）
    ├── page.css           # 填充结果高亮样式
    └── content.js         # content script 入口
```

## 可识别字段

- **基本信息**：姓名、性别、出生日期、手机、邮箱、证件号、政治面貌、最高学历、籍贯、现居城市、期望城市/薪资、通讯地址、QQ、微信、英语水平
- **教育经历（多条）**：毕业院校、学历、专业、入学/毕业时间、成绩 GPA、专业排名
- **项目经历（多条）**：项目名称、担任角色、起止时间、项目描述
- **实习经历（多条）**：实习公司、实习岗位、起止时间、实习内容
- **补充信息**：技能特长、获奖情况、自我评价

识别基于关键词加权匹配（label 文本 > name/id/placeholder 属性 > 邻近文本），规则见 `lib/fields.js`，可自行增删关键词以适配特定网站。

## 已知局限

- **文件上传**（简历附件、证件照）受浏览器安全限制无法自动填充，需手动选择
- 验证码、滑块不做处理
- 使用富文本编辑器（wangEditor、UEditor 等）的描述框暂不支持自动填充
- 复杂级联下拉（省市区联动等）可能匹配失败，面板中会标黄提示
- 多条经历按控件在 DOM 中出现的顺序对应资料记录；若页面组数不足，先在页面点击「添加」再重新扫描
- 在扩展安装前已打开的页面需刷新后才能使用

## 隐私

资料通过 `chrome.storage.local` 保存在本机，可通过资料管理页导出 JSON 备份、导入恢复。扩展无任何网络请求。
